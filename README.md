# Portfólio — Pedro Arthur Cardoso Filipponi

React + Vite. Sem APIs pagas.

## Rodar localmente
```
npm install
npm run dev
```
Abra o endereço mostrado (normalmente http://localhost:5173).

## Publicar na Vercel
1. Suba esta pasta para um repositório no GitHub.
2. Em vercel.com: Add New → Project → importe o repositório.
3. A Vercel detecta o Vite sozinha (Build: `npm run build`, Output: `dist`). Clique em Deploy.

## Editar conteúdo
Tudo em `src/data.js`: textos, links e imagens. Para artistas/canais, troque `url: null` pelo link correto.
As imagens do Simon ficam em `public/simon/` (simon-1.jpg … simon-5.jpg). Para trocar, substitua o arquivo mantendo o nome.

## Créditos das imagens
Algumas imagens trazem marcas de artistas (POFU, dravenlove99, crioffear, @simonshoodi3). Se for publicar, vale dar crédito ou pedir permissão.
